# Hi, I'm justsillyx! 👋

I build web tools and small utilities, mostly with TypeScript and Node.js, often backed by SQLite because sometimes a single file is all the database you need. I'm drawn to the indie web — the idea that you can ship something useful without a massive stack or a team of ten. Lately I've been thinking a lot about what it means to build pragmatically, to choose boring technology on purpose and still find the work genuinely interesting.
